# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and this project uses semantic versioning.

## [0.1.0] - 2026-09-20

### Added

- Portable personal development project workflow.
- Revision-checked JSON state model with deterministic Markdown rendering.
- Standard-library CLI for initialization, validation, application, rendering, and summaries.
- Skill, File, and Chat usage modes.
- Personal project example and cross-platform prompt scenarios.
- Git-aware confirmation and commit guidance without automatic pushes.
